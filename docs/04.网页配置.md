## 2、设置个人访问令牌（PAT)
第一步生成 Personal Access Token（PAT）
第二步：将 PAT 添加到仓库 Secrets
第三步：找到并修改工作流文件
将
- name: Deploy 🚀
  uses: JamesIves/github-pages-deploy-action@v4
  env:
    ACCESS_TOKEN: ${{ secrets.ACCESS_TOKEN }}
  with:
    folder: docs/.vuepress/dist
    branch: gh-pages
修改为：
- name: Deploy 🚀
  uses: JamesIves/github-pages-deploy-action@v4
  with:
    token: ${{ secrets.ACCESS_TOKEN }}   # 关键：这里指定 token
    folder: docs/.vuepress/dist
    branch: gh-pages
保存并提交修改
git add .
git commit -m "fix: 使用正确的 token 参数配置部署 action"
git push
