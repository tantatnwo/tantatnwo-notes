# 1、换仓库名字

github用户名为：tantatnwo 仓库名称：tantatnwo-notes 站点名称：https://tantatnwo.github.io/tantatnwo-notes

# 2、设置个人访问令牌（PAT)

第一步生成 Personal Access Token（PAT） 第二步：将 PAT 添加到仓库 Secrets 第三步：找到并修改工作流文件 将

- name: Deploy 🚀
  uses: JamesIves/github-pages-deploy-action@v4
  env:
    ACCESS_TOKEN: ${{ secrets.ACCESS_TOKEN }}
  with:
    folder: docs/.vuepress/dist
    branch: gh-pages
